# Как мы собираем проект вместе

## Первый этап

Пока работает один узел: eligibility. Он отвечает на вопрос «подходит ли заказ для нашего процесса анализа?». Он не оценивает надёжность клиента и не разрешает поставку.

Запуск из папки проекта:

```bash
PYTHONPATH=src python3 -m order_exception
```

На экране три примера:

1. Заказ на €120 000, кредитная блокировка, hard_stop=false: completed, eligible=true, collect_context.
2. Заказ на €180 000, кредитная блокировка, hard_stop=true: completed, eligible=false, manual_review.
3. Заказ на €160 000, кредитная блокировка, hard_stop=null: failed, eligible=null, manual_review.

В третьем случае система не знает, есть ли запрет. Она не может считать, что запрета нет.

## Что сделала я, Codex

- Подготовила структуру проекта и контракт общей карточки дела.
- Реализовала проверку обязательных полей и трёх условий допуска.
- Добавила synthetic events и тесты границ и некорректных данных.

## Что делает Анна

- Принимает бизнес-решения: сначала полномочия ревьюеров, затем допустимые действия.
- Разбирает небольшой работающий пример перед следующим этапом.
- Меняет один тестовый вход и объясняет ожидаемый результат до запуска.
- Объясняет на интервью назначение узлов, границы полномочий и обработку неизвестных данных.

## Следующее короткое упражнение

Кредитная блокировка, сумма €120 000, hard_stop=false. После сбора данных оказалось, что своевременных платежей всего 89%.

Объясни: почему такой заказ может быть eligible, хотя риск будет High? Кто должен его рассмотреть? Достаточно ли статуса eligible=true для снятия блока?

Код eligibility находится в src/order_exception/eligibility.py. Читай его тремя частями: проверка формата -> проверка бизнес-условий -> результат и маршрут. Агент и LLM для этого узла не нужны.

## Как будем двигаться

За один этап добавляем одну понятную способность и проверяем её. Следом — mock ERP/CRM и карточка фактов; затем документы и retrieval; потом риск и объяснение; дальше orchestration, review, execution и интерфейс.

Каждый этап завершаем четырьмя вопросами: что получает узел, что возвращает, чего ему нельзя делать, что происходит при ошибке.
